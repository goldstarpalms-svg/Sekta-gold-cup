# 🏆 SEKTA GOLD CUP — Ultimate AI Chatbot

Better than ChatGPT + Claude + Gemini + Perplexity — all in one.

## Features
- 8 Super Agents (Omni, Code Titan, Research Oracle, Creative God, etc.)
- Streaming chat with tool calling (web search, image gen, code execution)
- File analysis (PDF, CSV, XLSX, DOCX, images)
- Long-term memory
- DALL·E 3 image generation
- Voice (Whisper STT + TTS)

## Setup
Add your OpenAI API key in **Space Settings → Secrets**:
- `OPENAI_API_KEY` = `sk-proj-...`
- `TAVILY_API_KEY` = `tvly-...` (optional, for web search)
